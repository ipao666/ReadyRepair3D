# Ready3D V3 Top-1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成所有无需 GPU 服务器即可实现和验证的 Ready3D V3 Top-1 数据、训练、评测与服务器交接能力。

**Architecture:** 新增独立的 `r3dloop.ready3d_v3` 包，复用冻结 V2 的特征和质量标签，但不修改 V2 代码与实验结果。所有新功能由小型 CLI 包装，通过 JSONL manifest 连接 SANA、Hunyuan、评分和训练阶段。

**Tech Stack:** Python 3.10/3.11（本机兼容测试使用 3.13）、NumPy、SciPy、scikit-learn、pytest、JSONL、PowerShell/Bash。
