## 关键技术选择

**按提示词组划分，而非按图片划分。** 同一提示词的四个候选具有强相关性；跨集合混放会让测试不再反映对新提示词的泛化。成对排序在组内比较候选，模型和融合权重以验证集选择。

**区分自动 Q、技术有效与人工可用。** 文件能加载、八视角能渲染、拓扑指标合格，并不证明语义和视觉质量令人满意。当前自动 Q 未被独立人工标注验证，不能声称等价于人类偏好。

**保留成本匹配的基线。** V2 Top-2 比 Direct 多调用一次三维生成；V3 Top-1 则与结构规则等单次调用方案比较。V3 的结果没有超过结构基线，应分析数据规模、特征与排序泛化，不能通过更换展示基线制造成功结论。

**让回退成为正常输出。** 修复不是每次都必须改网格。保留原始文件并报告拒绝原因，可以避免把几何破坏掩盖为“修复成功”。

**使用独立盲测决定是否启用 LoRA。** 64 组最终实验的均值略升，但置信区间跨零且稳定性指标下降，因此保留 Base SANA。测试集已使用，后续改进必须使用新的隔离测试集。

可展示的能力包括 Python 工程、模型集成、传统机器学习排序、参数高效微调、三维资产处理、实验控制与失败分析。该项目不包含机器人控制或 VLA 策略训练，也未从零训练生成骨干。

1. 展示三份 GLB 与真实渲染，说明其来源及精选样例属性。
2. 运行 `python tools/verify_portfolio.py`，解释同资产评分一致性与基线均值重算。
3. 讲解一次候选选择，再解释 V3 为什么未超过结构规则。
4. 展示最终 LoRA 对照和保留 Base 的决策。
5. 进入修复回退代码，说明失败情况下如何保留输入资产。
